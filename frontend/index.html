    What's real: school name, location, category, and management type (datameet/udise_schools), plus the infrastructure signal below — functional toilets, library, computer, and internet access per district, 2019-20 (thejeshgn/udise-report-data-downloader, cached UDISE+ Public Reports). Two independent government-data pulls, joined cleanly on all 34 districts.

    What's still a modeling choice: the rural/"terminal primary"/govt-management rule is a documented assumption, not fitted to real outcomes. The infra signal is real but district-level — every school in a district currently shares one figure, since school-level infra data wasn't reachable at that granularity here. Treat the combined score as a transparent proxy, not a validated dropout-probability model.

    Real-data cross-check: using the same real UDISE+ cohort data behind the infra numbers, Karnataka's actual 2019-20 secondary dropout rate computes to 17.8% — closely matching a published national estimate (~17%) found separately during this project's research. Independent numbers, same ballpark.

    Framing: this tool scores schools and localities, never individual children, and is meant to help administrators plan where to route support — not to flag or rank any student.

    Deploy-units caveat: coverage radius is straight-line distance, not road travel time, and every unit is assumed to cost the same. Both are simplifications worth replacing with real routing/cost data before acting on the plan.
